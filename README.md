# Edge TTS 语音生成工具

基于微软 Edge 在线语音合成（edge-tts）的 Windows 桌面可视化工具，输入文字一键生成 MP3 语音广播。

## 功能特性

- **可视化界面**：文本输入、参数调节、状态反馈一体化
- **语音库在线加载**：自动获取微软全部 300+ 语音（中文语音置顶显示），支持关键字过滤，也可手动输入语音名称
- **参数可调**：语速（-100% ~ +200%）、音量（-100% ~ +100%）、音调（-50Hz ~ +50Hz），滑块与输入框双向联动
- **参数说明**：内置每个参数的详细说明与悬浮提示，说明区可滚动查看
- **一键试听**：生成完成后自动调用系统默认播放器播放
- **配置记忆**：所有参数自动保存到程序目录 `config.json`，下次打开自动恢复
- **故障自检**：启动时异步检查 edge-tts 是否有新版本，生成时若遭遇微软鉴权 403 会给出针对性升级指引（区分源码运行 / 便携 exe 模式）
- **完全便携**：单文件 exe，拷贝到任何 Windows 10/11 电脑即可使用，无需安装 Python

## 使用方法

### 便携版（推荐）

直接运行 `dist/EdgeTTS_VoiceTool.exe`（约 44 MB）：

1. 在"文本内容"区输入要转换的文字
2. 选择语音（默认 `zh-CN-YunxiNeural` 云希男声），需要其他语音可点击"刷新列表"
3. 按需调节语速 / 音量 / 音调
4. 设置输出文件名与保存目录（默认保存到程序目录）
5. 点击 **▶ 生成语音**，完成后自动试听

### 从源码运行

```bash
pip install -r requirements.txt
python src/main.py
```

### 重新打包

```bash
build.bat
```

产物输出至 `dist/EdgeTTS_VoiceTool.exe`。

## 参数说明

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 语音 | 300+ 种 | zh-CN-YunxiNeural | 格式：区域-语言-名称Neural，如 zh-CN-YunxiNeural（云希·阳光男声） |
| 语速 | -100% ~ +200% | -5% | -100% 最慢，+200% 最快，0% 正常；-5% 表示放慢 5% |
| 音量 | -100% ~ +100% | +0% | -100% 静音，+100% 最大 |
| 音调 | -50Hz ~ +50Hz | +0Hz | 正值更清脆，负值更低沉 |
| 输出 | - | broadcast.mp3 | MP3（24kHz / 48kbps / 单声道） |

> 注意：语音合成调用微软在线服务，生成时需保持网络连接。

## 故障自检机制

微软会不定期升级在线语音的鉴权算法（Sec-MS-GEC），旧版 edge-tts 生成的 token 会被服务端拒绝并返回 **403**，表现为"之前可用、突然报错"。

本工具内置两层自检：

1. **启动时版本检查**：异步查询 PyPI 最新版 edge-tts，若本地版本落后，状态栏提示"有新版本可用，旧版可能被微软鉴权拒绝"。
2. **运行时 403 识别**：生成语音或加载语音列表失败时，若异常为 403 鉴权错误，弹出针对性指引：
   - 源码运行模式：提示执行 `pip install --upgrade edge-tts` 后重启
   - 便携 exe 模式：提示下载使用最新版程序（exe 内 edge-tts 被冻结，pip 升级无效，需重新打包）
